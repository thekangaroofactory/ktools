# Scan Code

Generates a code report for a given path.

## Usage

``` r
scan_code(path = getwd())
```

## Arguments

- path:

  a path to scan

## Value

a data.frame with counts for the scanned files

## See also

[`count_lines()`](https://thekangaroofactory.github.io/ktools/reference/count_lines.md)

## Examples

``` r
if (FALSE) { # \dontrun{
scan_code()} # }
```
