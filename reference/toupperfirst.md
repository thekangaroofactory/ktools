# Capitalize First Letter

Capitalize First Letter

## Usage

``` r
toupperfirst(x)
```

## Arguments

- x:

  a character vector, or an object that can be coerced to character by
  as.character.

## Value

a character vector

## Examples

``` r
toupperfirst("capitalize first letter")
#> [1] "Capitalize first letter"
toupperfirst(1)
#> [1] "1"
```
