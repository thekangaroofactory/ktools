# Capitalize First Letters

Capitalize First Letters

## Usage

``` r
toupper_words(s, strict = FALSE)
```

## Arguments

- s:

  a character string

- strict:

  a logical (default = FALSE) if other characters should be forced to
  lower

## Value

a character string

## Examples

``` r
toupper_words("this is an example")
#> [1] "This Is An Example"
```
