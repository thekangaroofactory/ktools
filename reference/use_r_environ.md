# Create .Renviron File

Create .Renviron File

## Usage

``` r
use_r_environ(path = getwd())
```

## Arguments

- path:

  the path where to create the file (default set to working directory)

## Value

the output of the file.create call

## Examples

``` r
if (FALSE) { # \dontrun{
use_r_environ()
} # }
```
