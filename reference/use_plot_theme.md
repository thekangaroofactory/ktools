# Use Plot Theme Function

Helper function to create a theme function that can be used across the
project.

## Usage

``` r
use_plot_theme(path = getwd())
```

## Arguments

- path:

  where to copy the template

## Value

the output of copy_template()

## Examples

``` r
if (FALSE) { # \dontrun{
use_plot_theme()
} # }
```
