# Installation

Install the ktools package as follows:

## From R-universe

```{r}
install.packages('ktools', repos = c('https://thekangaroofactory.r-universe.dev', 'https://cloud.r-project.org'))
```

## From CRAN

```{r}
install.packages("ktools")
```
